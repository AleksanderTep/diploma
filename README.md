# Интеллектуальная система анализа тональности и приоритизации отзывов

Дипломный проект: система классификации русскоязычных отзывов на позитивные и негативные с автоматической приоритизацией для бизнеса.

## О проекте

Система анализирует текстовые отзывы клиентов, определяет их тональность, выделяет проблемные категории и присваивает приоритет для реагирования. Прототип демонстрирует полный ML-пайплайн: от предобработки текста до интерактивного интерфейса.

## Основные возможности

- **Классификация тональности**: позитив / негатив
- **Сравнение моделей**: TF-IDF + Logistic Regression vs RuBERT-tiny2
- **Предобработка текста**: очистка, стемминг, стоп-слова, сохранение смайликов и отрицаний
- **Категоризация негатива**: качество товара, доставка, сервис, комплектация, цена
- **Приоритизация**: высокий / средний / низкий приоритет обращений
- **Порог уверенности**: отзывы с низкой уверенностью отправляются на ручную проверку
- **Gradio-интерфейс**: анализ одного отзыва и пакетная обработка CSV
- **Визуализация**: графики распределения тональности, категорий и приоритетов

- **Python**

- **NLTK** — стемминг, стоп-слова

- **Google Colab** — среда разработки

## Как запустить

1. Скачай файл `.ipynb` из репозитория.
2. Загрузи в [Google Colab](https://colab.research.google.com/).
3. Установи зависимости (первая ячейка ноутбука):
   ```bash
   pip install numpy==1.26.4 pandas==2.2.2 scikit-learn==1.5.2 nltk==3.9.1 transformers==4.44.2 gradio
   ```
4. Запусти ячейки последовательно.
